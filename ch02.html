CHAPTER 02 · 数据的表示和运算

第 2 章 · 同样 8 个 0/1，怎样表示 −45？

这一章是计组的“数学地基”：补码让减法变加法，浮点让小数有统一格式，校验码让错误可被发现。408 在这里既考选择题，也常在大题里让你写 IEEE 754 编码、判断溢出、算海明码。

2.1 数制与编码：先把“位权”想清楚

🏦 生活类比
十进制像“满十进一的收银台”，二进制像“只有 0 元和 1 元两种面额的收银台”。同一个金额，可以用不同面额组合表示；位权就是每个位置代表的面额。二进制第 i 位的位权是 2ⁱ。

408 常考的进制转换不多，但必须快且准：

转换方法例子
二 → 十按位权展开求和1011₂ = 8+0+2+1 = 11
十 → 二（整数）除 2 取余，逆序排列45 → 101101₂
二 ↔ 八/十六3 位一组 / 4 位一组1011 0110₂ = B6₁₆
十 → 二（小数）乘 2 取整，顺序排列0.375 → 0.011₂

BCD 码用 4 位二进制表示一位十进制数（8421 码），例如 59 = 0101 1001。它和纯二进制不同：BCD 的 1010~1111 是无效编码。408 可能考“BCD 加法后是否需要加 6 修正”，了解即可。

2.2 定点数表示：原码、反码、补码、移码

定点数的小数点位置固定：要么固定在最低位之后（定点整数），要么固定在符号位之后（定点小数）。机器数把符号位也编进二进制，最高位通常为符号位（0 正 1 负）。

编码正数负数（以 −45 为例）8 位范围零的个数
原码符号位 0 + 绝对值1 010 1101 = 10101101−127 ~ +1272 个
反码同原码原码除符号位外按位取反 = 11010010−127 ~ +1272 个
补码同原码反码末位加 1 = 11010011−128 ~ +1271 个
移码补码符号位取反01010011（−45+128=83）−128 ~ +1271 个
📌 补码的本质：模 2ⁿ 的“同余”
n 位补码把负数 X 表示为 2ⁿ + X。例如 8 位时 −45 的补码 = 256 − 45 = 211 = 11010011。这样一来，A − B 可以变成 A + (2ⁿ − B)，减法器就可以用加法器实现。溢出被“模”自然丢掉，剩下的低 n 位就是正确结果（只要不超出范围）。

符号扩展与移位

符号扩展：把短补码扩展为长补码时，高位全部补符号位。例如 8 位 1000 1010 扩展到 16 位是 1111 1111 1000 1010；正数则补 0。

算术移位：左移末位补 0；右移高位补符号位。补码算术右移相当于除以 2 并向负无穷取整（−24 → −12，−25 → −13）。逻辑移位则不分符号，右移高位补 0。

⚠️ 左移会改变符号
补码左移一位相当于乘 2，但如果最高有效位被移出，符号会翻转，结果溢出。判断方法与加法溢出相同：移位前后符号位是否一致。

2.3 定点运算与溢出判断

补码加减法统一为加法：[A−B]补 = [A]补 + [−B]补，其中 [−B]补 是 [B]补 连同符号位一起取反再加 1。

[A + B]补 = [A]补 + [B]补 （mod 2ⁿ）
[A − B]补 = [A]补 + [−B]补

溢出判断的两种常用方法

方法判据说明
单符号位 + 进位符号位进位 Cin 与最高位进位 Cout 异或为 1Cin ⊕ Cout = 1 表示溢出；同号相加才可能溢出
双符号位（变形补码）00 / 11 正常；01 正溢；10 负溢两个符号位一起参与运算，最高位是真正的符号，次高位用于判溢
符号判断两正相加得负 → 正溢；两负相加得正 → 负溢最直观，适合口算检查

例：8 位补码 97 + 45。97 = 0110 0001，45 = 0010 1101，相加得 1000 1110。两个正数相加结果符号位为 1，发生正溢出；双符号位为 01。

🔬 实验室 1 · 补码加法与溢出
输入两个整数，选 8/16 位，观察双符号位和溢出判断。试试 97+45、−100−50、−128−1。

乘法与除法（概念 + 考法）

原码一位乘：符号位单独异或，绝对值相乘。每次根据乘数最低位决定“加被乘数”还是“加 0”，然后部分积右移。n 位需要 n 次“加 + 右移”。

Booth 补码乘法：把乘数末尾附加一位 Q−1=0，根据 Q₀Q₋₁ 的四种组合决定 +M、−M 或 0，然后算术右移。它可以直接处理带符号数，不必先取绝对值。

Q₀Q₋₁操作
00部分积 +0，算术右移
01部分积 +M，算术右移
10部分积 −M，算术右移
11部分积 +0，算术右移

除法：恢复余数法每次减除数，若余数为负就加回来；加减交替法（不恢复余数法）根据余数符号决定下一步加还是减，步骤更少。408 选择题可能考“需要多少次加减/移位”，掌握流程即可。

2.4 浮点数：小数点会“浮动”

🔬 生活类比
浮点数像科学计数法：123000 可以写成 1.23×10⁵，0.00123 写成 1.23×10⁻³。小数点位置随阶码移动，所以叫“浮点”。计算机用二进制做同样的事：符号 + 阶码 + 尾数。

一个浮点数的值可以写成：

V = (−1)S × M × 2E

其中 S 是符号位，M 是尾数（规格化后通常为 1.xxx），E 是阶码（实际指数）。为了用定点整数表示负指数，IEEE 754 使用偏置阶码：存储的阶码字段 = 实际指数 + 偏置值。

格式总位数符号 S阶码 E尾数 M偏置
单精度 float321823127
双精度 double64111521023

规格化与隐含的 1

规格化浮点数的尾数满足 1 ≤ M < 2，二进制形式为 1.xxxxx。既然最高位总是 1，IEEE 754 就不存这个 1，只存小数点后的 23/52 位，相当于白赚一位精度。所以单精度有效位数是 24 位（1 位隐含 + 23 位显式）。

例：把 −12.375 转成单精度。

12.375 = 1100.011₂ = 1.100011₂ × 2³
S = 1（负数）
E = 3 + 127 = 130 = 10000010₂
M = 10001100000000000000000₂（小数点后 23 位）
拼接：1 10000010 10001100000000000000000
十六进制：0xC1460000
🔬 实验室 2 · IEEE 754 转换器
支持单/双精度。输入十进制数点“十进制 → 浮点”，或输入十六进制点“十六进制 → 十进制”。试试 −12.375、0.1、3.4e38、1e-45。

特殊值与表示范围

阶码 E尾数 M含义
全 0全 0±0（符号位决定 +0/−0）
全 0非 0非规格化数，值 = 0.M × 21−bias
全 1全 0±∞
全 1非 0NaN（非数）
1 ~ 254任意规格化数，值 = 1.M × 2E−127

单精度的关键量级：最大正数约 3.4×10³⁸，最小正规格化数约 1.18×10⁻³⁸，最小正非规格化数约 1.4×10⁻⁴⁵，有效十进制位数约 7 位。双精度对应约 1.8×10³⁰⁸、2.2×10⁻³⁰⁸、5×10⁻³²⁴、16 位有效数字。

2.5 浮点运算：五步走

对阶：比较两个数的阶码，小阶向大阶看齐。小阶数的尾数右移，每右移一位阶码加 1。
尾数加减：阶码统一后，对尾数做加/减。注意尾数是带符号的定点小数。
规格化：若尾数最高位不是 1，左规（尾数左移、阶码减）；若尾数溢出（出现 10.xxx 或 01.xxx），右规（尾数右移、阶码加）。
舍入：右移或规格化可能丢位，按 IEEE 754 的舍入方式处理。默认“就近舍入到偶数”。
溢出判断：阶码超出上限 → 溢出（∞）；低于下限 → 下溢（按 0 或非规格化数处理）。
⚠️ 为什么小阶向大阶看齐？
如果让大阶数的尾数左移去迁就小阶，尾数可能超出表示范围而丢失高位，造成大数被破坏。让小阶数的尾数右移，丢的是低位（精度损失），不会破坏数量级。所以对阶方向不能反。

舍入方式

方式规则特点
就近舍入到偶数最接近的值；正好居中时取偶数IEEE 754 默认，误差最小且无统计偏差
朝零舍入直接截断实现简单，误差偏向零
朝 +∞ / −∞向正/负方向取最近可表示值用于区间运算

经典问题：0.1 + 0.2 在双精度下不等于 0.3，而是 0.30000000000000004。因为 0.1、0.2、0.3 都不能用有限二进制精确表示，存储时已经舍入，相加后再舍入，误差就显现出来。这不是“计算机算错了”，而是二进制浮点的表示精度问题。

2.6 校验码：让错误暴露出来

奇偶校验

在数据后加 1 位校验位，使整个码字中 1 的个数为奇数（奇校验）或偶数（偶校验）。它只能检测奇数个位出错，不能纠错；偶数个位同时出错会漏检。

海明码：能定位 1 位错误

设数据位 n 位、校验位 k 位，需满足：

2k ≥ n + k + 1

校验位放在 2⁰、2¹、2²…（即第 1、2、4、8… 位），其余位置放数据。每个校验位负责一组位置（按位置编号的二进制位分组），用偶校验或奇校验填充。接收端重新计算各组校验值，得到的故障字直接指出出错位置。

例：n=4，k=3，总码字 7 位。数据放在 3、5、6、7 位，校验位在 1、2、4 位：

校验位负责的位置依据
P1（第 1 位）1, 3, 5, 7位置编号最低位为 1
P2（第 2 位）2, 3, 6, 7位置编号次低位为 1
P4（第 4 位）4, 5, 6, 7位置编号第 3 位为 1

海明码可纠正 1 位错误、检测 2 位错误（标准海明码对 2 位错误可能误纠，实际常用扩展海明码加 1 位总校验位）。

CRC：模 2 除法

CRC 把数据看成多项式，用一个生成多项式 G(x) 去除，余数作为校验位。若 G(x) 的最高次为 r，则校验位 r 位。发送方把数据左移 r 位后做模 2 除法（异或，不借位），余数附在数据后。

例：数据 1101，G(x)=x³+x+1 → 1011（r=3）。数据左移 3 位得 1101000，除以 1011：

1101000 ÷ 1011（模 2 除）
余数 = 001
发送码字 = 1101 001

接收方用同一 G(x) 除收到的码字，余数为 0 则认为无错（或错误未检出）。CRC 检错能力强、实现简单，广泛用于网络和存储。

🚀 进阶深挖（教材级）

深挖 1 · 为什么补码的符号位可以参与运算？

因为补码把有符号数映射到模 2ⁿ 的同余类：−45 和 211 在模 256 下等价。加法器只做无符号加法，高位进位自然丢弃，结果仍然落在正确的同余类里。只要真实结果在 [−2ⁿ⁻¹, 2ⁿ⁻¹−1] 内，低 n 位就是正确的补码；超出范围才发生溢出。

深挖 2 · 浮点数的“精度”和“范围”不是一回事

范围由阶码位数决定，精度由尾数位数决定。单精度尾数 23 位，约 7 位十进制有效数字；双精度 52 位，约 16 位。一个数可以很大（范围够）但很粗糙（精度不够），例如 1e20 在单精度下只能表示到约 7 位有效数字。做题时先问：题目要的是“能表示多大”还是“能精确到几位”。

深挖 3 · 海明码故障字与纠错

接收端对每组重新做偶校验，若第 1 组错记 1、第 2 组错记 2、第 4 组错记 4，把出错的组号相加，得到的数就是出错位的位置。例如故障字为 6 = 2+4，说明第 6 位出错，取反即可纠正。若故障字为 0，说明无错（或错误恰好互相抵消）。

🌐 多源视角
  • 【唐朔飞】把补码定义为“模 2ⁿ 意义下的机器数”，先讲模运算再讲编码。本站用法：遇到“为什么补码能表示 −128”时，回到 2⁸=256 的同余类，不要死记范围。
  • 【CSAPP】用“位向量 + 无符号/有符号解释”讲同一串位。本站用法：同一串 11111111，无符号是 255，补码是 −1，原码是 −127；题目问“值”之前先确认编码。
  • 【IEEE 754 标准】把浮点分成规格化、非规格化、无穷、NaN 四类，并规定默认舍入为“就近到偶数”。本站用法：看到 E 全 0 或全 1，先查特殊值表，不要代普通公式。
参考：唐朔飞《计算机组成原理》第 2、6 章；CSAPP 第 2 章；IEEE 754-2019。

⚠️ 本章避坑清单

补码的 −128 没有对应的原码/反码（8 位原码最小是 −127），题目说“求 −128 的原码”是在挖坑。
符号扩展补的是符号位，不是补 0；只有正数才补 0。
算术右移高位补符号位，逻辑右移高位补 0；C 语言里有符号数右移通常是算术右移，但标准未完全规定，考试按算术右移。
IEEE 754 的阶码是偏置后的无符号数，实际指数 = 阶码 − 127（单精度）；不要把 130 当成实际指数。
规格化数有隐含的 1，非规格化数没有；E 全 0 时不能用 1.M 公式。
浮点对阶是小阶向大阶看齐，不是大阶向小阶。
海明码校验位放在 1、2、4、8… 位，不是放在末尾；CRC 余数位数等于生成多项式最高次，不是数据位数。
