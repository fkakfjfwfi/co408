📌 408 计组的分值感
408 总分 150：数据结构 45 + 计算机组成原理 45 + 操作系统 35 + 计算机网络 25。计组通常 11 道选择（22 分）+ 2 道综合题（约 23 分），是“选择决定下限、大题决定上限”的科目。具体题量每年略有浮动，但存储系统、CPU、数据表示三块始终是重心。

🧭 学习路径（零基础 / 跨考适用）

第 0 步 · 先读方法论：去备考方法论把“三轮怎么切、错题本怎么写、大题怎么拿步骤分”看一遍。方法错了，后面投入全废。
第 1 步 · 按 01 → 07 过章：每章先看“这一章在整机里的位置” → 读生活类比 → 读分节详解 → 动手玩实验室 → 做章内练习 → 完成打卡。
第 2 步 · 用练习场查漏：去练习场按章节/难度筛选，先做基础，再做提高和真题改编；错题自动进错题本，用“只看错题”重做三遍。
第 3 步 · 配合教材：以唐朔飞/袁春风教材或王道单科书为主线，本站当作“看不懂时的可视化字典”。看到公式就回到对应实验室改参数验证。
第 4 步 · 大题动手写：Cache 地址划分、主存扩展、数据通路微操作、流水线时空图，必须在纸上完整写一遍，不能只看懂。每道大题按“公式 + 代入 + 结果 + 单位”四行写。
